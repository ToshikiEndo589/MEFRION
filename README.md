# MEFRION

**犬と猫が主役のiPhone向けSNS。** 写真や動画を見て楽しみ、うちの子の思い出を残し、写真から見た目が似た犬猫を探せるアプリです。犬猫を飼っていない人も、ゲストとして公開投稿とコメントを閲覧できます。

> 現在はApp Store公開に向けた準備段階です。このリポジトリにはアプリ、バックエンド、案内・運営サイト、テストと提出用素材が含まれます。GitHub上のコードを公開しても、App Storeでの配信開始を意味しません。

## アプリでできること

| 画面 | 体験 |
| --- | --- |
| **ホーム** | 犬猫の公開投稿を写真・動画で見る。「おすすめ」と「フォロー中」を切り替え、気になる投稿にいいねやコメントを送る。 |
| **検索** | 犬猫の名前や犬種・猫種からアカウントと関連投稿を探す。 |
| **アルバム** | うちの子の写真・動画を非公開で残す。家族を招待して一緒に見たり、「しぐさ図鑑」でお気に入りの瞬間を集めたりできる。 |
| **投稿** | 写真と動画を合わせて最大10件選び、順番を整え、ひとことを添える。「公開投稿」と「アルバムに残す」を選べる。 |
| **そっくり** | 犬猫の写真を選ぶか撮影して、見た目が似た参考写真を探す。検索写真と結果の履歴は端末内で24時間確認できる。 |
| **マイページ** | 自分とうちの子のプロフィール、投稿、いいね・保存した投稿、フォロー、通知、家族アルバムの設定、アカウント削除を管理する。 |

初回画面では「登録して始める」と「ゲストユーザとして始める」を選べます。登録に犬猫の飼育は必要ありません。公開投稿への反応や投稿、私的アルバムの利用にはアカウントが必要です。

### 公開と非公開の区別

アルバムは非公開を基本とし、写真や動画をアルバムへ残しただけでは公開投稿になりません。公開投稿は投稿画面で明示的に選びます。家族への共有は招待で管理し、公開SNSへの投稿とは別の操作です。

### そっくり検索について

写真から特徴データを作って類似した参考写真を探します。元の検索写真そのものは検索サーバーへ送りません。結果は**見た目の類似候補**であり、同じ個体・血縁・病気を判定する機能ではありません。参考写真にはPexels由来の素材が含まれます。

### 安心して使うための機能

公開投稿とコメントの通報、ユーザーのブロック、運営による公開前確認と対応、公開の停止、アプリ内でのアカウント削除を用意しています。投稿した写真・動画の処理や公開可否はサーバー側でも確認します。

## 構成

- **iPhoneアプリ**：SwiftUI。Xcodeプロジェクトは [ios/MEFRION.xcodeproj](ios/MEFRION.xcodeproj)。撮影・選択、画面表示、端末内の画像特徴処理を担当します。
- **本番バックエンド**：Supabase Auth、Postgres、Storage、Edge Functions。ログイン、投稿、アルバムの権限、検索、通報、メディア処理、削除などを担当します。SQL変更は [supabase/migrations](supabase/migrations)、関数は [supabase/functions](supabase/functions) にあります。
- **案内・運営サイト**：Vercelで公開するサイトのソースは [sites/mefrion-info](sites/mefrion-info)。サポート、プライバシー、利用規約、招待・共有ページ、権限を持つ担当者向けの運営画面を含みます。
- **テストと運用資料**：自動テストは [tests](tests)、iOSのテストは [ios/MEFRIONTests](ios/MEFRIONTests) と [ios/MEFRIONUITests](ios/MEFRIONUITests)。本番運用手順は [docs/operations](docs/operations)、App Store用の記録は [release/app-store](release/app-store)。

一般利用者の写真を公開する処理と、家族だけで見る原本へのアクセスは分けて管理します。管理用の秘密鍵はアプリに同梱しません。

## 開発・検証

1. macOSでXcodeを開き、iOSのMEFRIONプロジェクトで **MEFRION** スキームを選びます。
2. iPhone Simulatorまたは署名設定済みの実機を選んで実行します。
3. クラウドを使う画面には環境別の公開接続設定が必要です。サーバー秘密鍵を端末やGitに入れないでください。設定手順は [本番iOS設定](docs/operations/PRODUCTION-IOS-CONFIG.md) を参照してください。

Pythonの検査は次のコマンドで実行できます。環境によっては requirements.txt の依存関係のインストールが必要です。

    python3 -m pip install -r requirements.txt
    python3 -m unittest discover -s tests
    python3 scripts/check_repository.py

過去の試作用に、ローカルAPIとWeb画面も [backend](backend) と [web](web) に残しています。これは本番iPhoneアプリのサーバーではありません。

## 公開状況と素材

App Store Connectへのビルド登録とストア表示の準備を進めていますが、**審査への提出・一般公開はまだ行っていません**。現在の選択ビルドや配信地域は [App Store Connect準備状況](release/app-store/ASC_STATUS.md) に記録しています。

初期掲載写真とそっくり検索の参考写真には第三者の素材が含まれます。Pexelsの利用条件に加え、素材ごとの権利や利用範囲を公開前に確認する必要があります。ユーザー投稿の権利は投稿者または元の権利者に残り、サービス運営に必要な範囲で利用します。正式な条件は公開サイトの利用規約を参照してください。
