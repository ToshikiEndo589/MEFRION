# そっくり参考写真を使う運営投稿計画

`queue.csv` / `queue.jsonl` は、既存のそっくり検索索引に採用された犬猫写真を使う**未承認の配信計画**です。初日100件、その後365日間は毎日30件、合計11,050件を重複なしで割り当てました。日本時間の初日は10:00〜10:09に毎分10件ずつ、日次は09:00・13:00・18:00の各10分に毎分1件ずつを予定しています。日付は仮置きです。実際の開始日は有効化時に再生成します。`managed-pets.csv` は、写真ごとに異なるPetプロフィールIDを作る計画です。表示名は犬猫の名前で、同じ名前が再登場しても別プロフィールとして扱います。`initial-100-contact-sheet.jpg` で初回候補を一覧できます。

撮影者、Pexelsページ、ローカルJPEG、SHA-256を各行に保存しました。犬・猫の種別はそっくり用のVision選別結果と取得時のカテゴリが一致したものに限定し、掲載終了を確認した `pexels-1790445` は除外しています。各行の `rights_state=pending_individual_review` と `review_status=pending_visual_review` は、**投稿掲載権利の承認や全件目視が済んだ意味ではありません**。

2026-10-16に計画を再生成し、投稿ごとの `pet_profile_key`、`pet_name`、`pet_breed` を追加しました。犬種・猫種を出典の説明から確認できない写真は品種を空欄にします。「推定」「未確認」は表示しません。名前は演出上のPet名であり、実在個体や飼い主を特定した意味ではありません。撮影者・出典と権利記録を保持し、年齢・所在地・体験談・いいね/コメント数は作りません。Pexels写真を所有Petの家族アルバムや個体一致の正解データとして扱いません。

本番公開には、各写真の画面確認、Pexelsの大量利用許可の証跡確認、運営MFA権限での管理Pet/写真の非公開登録・画像ごとの権利記録・下書き承認・予約、公開画像workerと常時実行の配信workerが必要です。既存の `mefrion_seed_dispatch` は予約済みのジョブを最大10件/回公開し、既存の管理画面で取消・権利撤回・一括停止ができます。現在はこれらの登録や日次workerの本番常時稼働が未完了なので、**100件も日次30件もまだ実際には公開されていません**。

Pexels公式の[ライセンス](https://www.pexels.com/license/)はアプリ内利用を認める一方、[API利用条件の説明](https://help.pexels.com/hc/en-us/articles/900005880463-What-are-the-Terms-and-Conditions)は無許可の大量収集・データセット化を制限しています。ユーザーは明示許可取得済みと申告していますが、許可書自体は未受領です。公開前に用途・件数を含めて確認します。API経由利用では[撮影者とPexelsへのクレジット](https://www.pexels.com/api/documentation/)も画面上で維持します。

再生成: `python3 scripts/plan_stock_seed.py --start-date YYYY-MM-DD --days 365`。写真在庫が尽きる場合は再利用せずエラーで停止します。
