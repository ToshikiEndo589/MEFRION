# App Privacy申告用データ棚卸し（下書き入力済み / 2026-10-22）

App Store Connectに6種類（メールアドレス、写真・動画、その他のユーザーコンテンツ、検索履歴、ユーザーID、製品の操作）を下書き入力した。いずれも追跡なし、ユーザーへの関連付けあり。用途はアプリ機能、ユーザーIDと製品の操作のみおすすめ等のパーソナライズも選択した。プライバシーポリシーURLと公開は未完了。実際の配備先、ログ、委託先、保持期限と突合してから確定する。

| データ候補 | 利用目的案 | 主な処理経路 | 確認状態 |
|---|---|---|---|
| メール、認証ID、表示名 | アカウント・復旧・表示 | 認証/DB | 実プロバイダー未設定 |
| Pet情報、写真、撮影日 | 非公開アルバム・公開を選んだ場合の表示 | DB/Private Storage/公開派生 | 本番の保存・削除運用未検証 |
| 投稿、コメント、いいね、フォロー | SNS機能 | DB/配信 | 実配備で再確認 |
| 招待、家族権限 | 家族共有・認可 | DB | 正式共有ホスト未設定 |
| そっくり検索の特徴数値、指紋、種類、試行ID | 参考写真との比較、回数制限 | 端末/検索RPC | 特徴は保存しない設計。通信基盤ログ要確認 |
| 通知先・設定 | 選んだ通知の配信 | DB/APNs予定 | APNs未設定 |
| 通報・ブロック・運営監査 | 安全運営 | DB | 有人対応・保持期限未検証 |
| 障害ログ・利用回数 | 障害対応・上限管理 | 開発ログ/DB | 本番ログのデータ・期限未確定 |

広告・第三者追跡を導入していないという現行設計と、実際のSDK/サーバー通信を公開ビルドで再照合する。PrivacyInfo.xcprivacyだけでApp Store Connectの申告は完了しない。
