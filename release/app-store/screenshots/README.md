# App Storeスクリーンショット素材

日本語iPhone版。撮影はiPhone 18 Pro Simulator（1206×2622）、実際のMEFRION SwiftUI画面から行う。`--ui-test-isolated --appstore-screenshots`はDebug撮影専用で、バックエンドや実ユーザーのデータを変更しない。Releaseビルドでは撮影用の投稿データ生成コードは有効にならない。

掲載順：`01-home.png`（おすすめ）、`02-album.png`（家族アルバム）、`03-post.png`（投稿作成）、`04-twins.png`（そっくり）、`05-my-page.png`（マイページ・履歴）。「あの頃と今」はアプリから外したため、旧画面の画像は掲載しない。

画面内の犬猫写真は、運営者が利用を指示したPexels写真のローカル在庫から選んだサンプル。撮影用の表示名や反応数はサンプルデータであり、実ユーザーの投稿や反応数ではない。審査前に実機の本番機能と画面構成を照合する。
