# 2026-10-08 受領UIと適用方針
正式名称は **MEFRION**。10枚の画像はUI参考であり、旧名称・画像内文言・数字を仕様変更の指示とは扱わない。
2026-10-09のユーザーによる追加指示は参考画像より優先する。ホームは**左「おすすめ」を初期選択、右「フォロー中」**。30の画面・状態への対応と実行した検証は `docs/evidence/UI-TEN-SCREENS.md` に記録。
原本を `design/reference/01.png`〜`10.png` に保存、SHA256をmanifest.jsonに記録。

| 画像 | 適用 | 確定仕様に合わせる差分 |
|---|---|---|
| 01 | 導入、認証、招待のカード構成 | 本認証接続前にApple/Google成功を表示しない、招待は認証後の一回承認 |
| 02 | ホームの上下構成、Pet横一覧、写真カード、詳細 | 犬猫のみ、実反応だけ、全体で運営制作を説明 |
| 03 | Petカバー/丸アイコン/編集構成 | 初期非公開、公開Petに人間の情報・フォロー中数を出さない |
| 04 | 時系列グリッド、日付、写真追加と再送、節目編集 | 日付不明/年だけを維持、最初から原写真の保存手段を計画 |
| 05 | 招待/家族一覧/新着 | 管理者と招待家族の確定権限を守る、複数回招待リンクは使わない |
| 06 | 振り返り/比較/縦カード | 私的保存が先、公開は別の明示確認・提供者同意 |
| 07 | 投稿/確認/コメント | 写真最大4・本文500、動画/位置情報/フォロワー限定は初期仕様へ自動追加しない |
| 08 | Twins入力/確認/主候補と補助/履歴 | 類似率を表示しない、主1補助最大2、少ない時は水増ししない |
| 09 | 公開Pet検索/通知/設定 | 人間の私的プロフィールや家族内写真を検索しない、通知は文脈内許可 |
| 10 | マイページ/Pet一覧/保存/設定 | 人間AccountとPetを区別、退会の削除連動・運営を省略しない |

色/余白/文字は共通トークン、写真は端末選択または権利を持つ開発イラストを使う。
参考画像に含まれる写真・人間画像を本番素材として切り出さない。掲載権利の確認は別工程。
