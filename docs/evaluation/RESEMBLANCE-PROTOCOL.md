# そっくり検索の比較手順（2026-10-11、結果確認前に固定）

- 母集団: 既存Pexels参考索引14,915枚。公開終了した1枚は配信対象から除く。
- 入力: IDのSHA256(`mefrion-eval-20261011:` + ID)順で犬12枚・猫12枚。結果を見て入力を選び直さない。人物と犬の写真、後ろ姿、白黒写真も含む。
- 旧方式: Apple Vision revision 2、768次元のユークリッド距離。
- 新方式案: DINOv2 small 正規化384次元、検出できた顔/動物領域、コサイン距離＋低い重み0.12の色ヒストグラム距離。係数は比較結果を見る前の仮定であり最適値としない。
- 自己写真/画像指紋/従来ベクトルの近重複除外は両方式共通。
- 画面評価: 各上位3件に対し、0=顔・体型や模様が大きく違う、1=大まかな形または毛色/模様が共通、2=形と毛色/模様の双方が近い。白黒・後ろ姿・複数主体はその制約を注記する。
- 評価者: 開発エージェントによる画像レビュー。ユーザーによる独立評価ではなく、汎用的な精度/識別精度の保証には使わない。血縁/同一個体の判定は対象外。
- 報告: 全24入力を残し、旧/新双方の結果ID、点数、改善・同点・悪化件数を記録。モデル置換の動作検証とは分ける。
- 実装時は旧クライアント/APIとの互換性を保持し、数値モデル版を照合。新旧ベクトルを混ぜない。

## 最初の探索比較後の補強
同じ撮影シリーズが新旧双方の結果に含まれたため、固定24入力は維持し、採点前に「入力と同じcreditの候補」を両方式から除外した。これは独立写真での比較のための評価専用条件。製品では入力写真の撮影者情報を取得/送信しない。新方式の結果3件は同一credit最大1件にして撮影シリーズの重複を抑える。比較は盲検でも独立ユーザー評価でもなく、結果確認後のこの補強も明記する。
