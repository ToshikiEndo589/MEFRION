# ホーム・タブ・そっくりの余白調整 — 2026-10-10

ホームの上余白16ptを削除し、見出し間隔を4ptへ縮小。おすすめ/フォロー中を13pt、行の高さ44pt、選択線2ptにした。MEFRIONは18ptのまま安全領域の直下へ移動。下部5タブは68ptから52ptへ縮小、中央＋は36pt、アイコン領域34pt。ホームインジケータとステータス領域は保持する。
