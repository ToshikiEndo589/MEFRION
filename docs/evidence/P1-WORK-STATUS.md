## 発見した不具合と修正

- 写真確認が単独では成功しても総合UIで0枚になる問題を再現。Boolean表示と写真配列の別更新を、写真を持つIdentifiableのsheet状態へ変更。初回修正2回は34成功/1失敗。最終35成功の証拠を優先し、`p1-completion-regression` / `p1-completion-confirmed` / `p1-completion-review-state` の失敗記録も保持する。
- Simulator Visionは候補順序・実行状態で不安定で、異なる所有イラストに同一特徴を返すことを確認。初期CPU方式へ変更。過去のVision単独成功を実写真の類似品質証拠にしない。
- 運営素材のブラウザープレビューでCORS失敗。private-imageの認証を維持したまま、承認済み検証UIのループバックOriginだけを許可。4実HTTP条件と実画像表示で確認。
- 運営の認証/権限拒否後に素材DOMが残る問題を修正。401/403でセッション・素材・Blob URLを消去。実ブラウザーでカード0/画像0/ログイン画面復帰を確認 (`p1-seed-auth-expired-cleared.png`)。
- 保管済みPetの素材削除が拒否される問題をmigration041で修正。MFA付きeditorと運営Pet所属を要求し、通常の家族写真・匿名・第三者・暗黙削除は拒否。削除/冪等/共有終了/通常UI写真の不存在を含む14項目成功 (`p1-owned-fixture-cleanup.json`)。
