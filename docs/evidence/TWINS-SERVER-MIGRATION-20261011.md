# 参考写真検索のサーバー移行と追加取得 — 2026-10-11

## 実装・配備できたこと

- 通常のiPhone参考写真検索を、端末内の全候補比較から既存Supabase Freeのpgvector/HNSW検索へ変更。
- iPhoneは768個のVision特徴と144bitの近重複指紋・平均明度・種類を同意後だけ送信。入力JPEGを送信・保存・候補登録しない。
- 犬猫別に近い100候補を取得し、暫定距離基準・同一写真/候補同士の近重複を除いて最大3件を返す。画像配信・履歴取得でも掲載状態を確認する。
- メタデータ/ベクトルはservice_roleのみ、画像はprivateバケットに保存。既存public-imageに参考写真用の状態再確認とno-store配信を追加して開発環境へデプロイ。既存家族原本・実Petの公開/同意/ブロック経路の権限を広げない。
- 参考検索専用の開発上限はゲスト10/会員50回/JST日。10分以内の同じUUIDの再試行・同時再試行は1回消費。実Pet検索の既存上限は変更しない。
- UI・アプリ内プライバシー案・文書を特徴データ送信方式に更新。入力が変わる/種類変更時は再同意と別UUID。本人限定の任意ID履歴24時間、入力10分/画面終了/非アクティブ時の破棄、外部共有の別同意を維持。
- 実機用ビルドから大きなTwinsReferenceDataを除外。署名を保持したDebug iPhoneビルド成功、アプリ19,068,129 bytes、全候補索引の同梱なし。Simulator隔離試験には旧索引を保持。

サムネイル208,648,645 bytes、特徴ベクトル45,818,880 bytes。DBの実測は新参考表＋索引123 MB、既存開発DB全体159 MB（PostgreSQL pg_size_pretty）。Freeプロジェクトを継続し、有料化・新規契約なし。

途中の4,200件掲載後にRemoteDisconnectedが発生。接続切断を捕捉して再試行する処理を補強し、登録済みを保持して残り10,715件を再開・掲載。最終失敗0。再取り込み試験では既存掲載/撤回14,915件をすべてスキップし、新規掲載0、撤回写真を復活させないことを確認。
