# ホーム投稿の全幅表示（2026-10-13）

利用者の参考スクリーンショットを基準に、iPhoneのクラウドホーム（おすすめ・フォロー中）だけを変更した。投稿写真を左右余白なしで表示し、Petのアイコン・名前・フォロー・メニューを上に、いいね数・コメント数・保存を写真の直下に配置。複数枚の写真も各枚を全幅で表示する。写真は元の縦横比を尊重しつつ、極端な比率だけ表示枠を制限する。本文は3行プレビューと詳細への「続きを読む」にした。

操作は既存の公開投稿権限に接続し、ゲストのいいね・コメント・保存・フォローは認証案内へ進む。通報とブロックは投稿の「…」メニューに残した。検索・投稿詳細画面の既存レイアウト、家族内アルバムや公開同意の条件は変更していない。

検証: iOS Simulator Debugビルド成功。既存のホーム横スワイプ/投稿先切替UIテスト1件成功。承認済みの一時公開投稿20件を使う追加UIテスト1件で、画像が画面全幅であること、いいねとコメントが同じ操作列にあること、ゲストのいいねが認証案内へ進むことを確認。テスト用の一時マーカーは削除した。修正版をSimulatorで起動し、[画面キャプチャ](HOME-EDGE-TO-EDGE-20261013.png)を確認した。実iPhoneへの今回の更新インストール・実機目視は未実施。
