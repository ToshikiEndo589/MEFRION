# そっくり画面の簡素化 — 2026-10-17

## 変更

- メイン画面は「写真を選ぶ」「写真を撮る」「この写真で検索する」の3操作を中心にした。初期画面の候補写真・件数・長い説明と、結果の「参考写真」見出し、評価ボタン、検索時間表示を削除。
- 犬猫の切り替えをなくし、選択した写真を端末内のVisionで判定してから既存の検索経路へ渡す。判定できない画像はエラーを表示する。
- 結果を大きな角丸写真にし、入力写真を小さく重ねた。写真の撮影者とPexelsへのリンクは表示する。ストック写真に架空のPet名・飼い主名を付けない。
- 履歴、公開Pet検索、写真調整、入力削除、結果保存、共有、処理説明は右上の「その他」にまとめた。保存・外部共有の既存の確認と権限は変更しない。
- 通常起動ではテスト用写真ボタンを表示せず、明示的なUIテスト起動引数がある場合のみ表示する。初期画面でサーバーから候補を先読みしない。

## 限界

物理iPhoneでの画面目視や撮影操作は今回行っていない。検索アルゴリズムと候補データの品質は今回変更していないため、「似ている」精度の改善を示すものではない。撮影者リンクは残し、結果の写真を実在ユーザーの投稿やPetプロフィールとして扱わない。
