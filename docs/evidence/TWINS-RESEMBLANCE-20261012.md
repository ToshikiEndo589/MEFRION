# そっくり比較モデル更新 — 2026-10-12

## 実装と配備
参考写真検索を汎用Vision特徴からDINOv2 smallの384次元特徴へ更新。検出できる場合は目・鼻・耳から頭部を切り抜き、それ以外は動物領域を使用。64次元の毛色ヒストグラムを重み0.12で加え、サーバーで近い240候補から並べ替える。自己写真・近重複を除外し、最大3件は同じ撮影者につき1件とする。

犬猫の顔専用に学習したモデルではない。掲載中写真の頭部切り抜きは2,281枚で、全写真の顔検出成功とは扱わない。係数・距離閾値は暫定値。

既存Supabase Freeへ別索引・v2 RPCを追加し、旧APIと索引を保持。新索引14,907件、掲載中14,906件（犬9,185・猫5,721）。旧索引の8件は新前処理で検出できず除外し、既に掲載終了した1件は復活させていない。DB全体218 MB。今回の写真追加取得・有料サービス導入はない。

入力写真そのものは端末内に保持し、個別同意後に特徴数値だけを送信する。モデルは端末、大量候補との比較はサーバーで実行。既存の家族写真・公開Pet・権限経路を維持。モデルのApache-2.0全文と出典はアプリ設定から閲覧可能。

## 比較結果と限界
固定した犬12枚・猫12枚の各上位3候補を0〜2点で開発エージェントが目視採点。合計は旧81点、新119点（各144点満点）。入力ごとは改善18、同点3、悪化3。小型の三毛犬、丸顔の白猫、サビ猫模様などで悪化が残る。

盲検でも独立ユーザー評価でもなく、一般的な精度率ではない。最初の探索比較後、採点前に入力と同じ撮影者を両方式から除外する条件を追加。入力24枚は変更していない。候補・採点・比較画像はresemblance-evaluation/、手順は../evaluation/RESEMBLANCE-PROTOCOL.md。
