# 通知設定・お知らせの整理

2026-10-24。マイページの「通知設定」、歯車内の「通知設定」、通知一覧の右上を同じ設定画面へ統一。

- 「Twinsのクラウド通知は準備中」「アプリ内通知の表示を設定します…」「設定を保存」を撤去。オン/オフの変更を自動保存。
- いいね、コメント/返信、フォローと、参加中の犬猫ごとの家族アルバム設定を集約。写真/動画の新着（オフ/そのつど/1日分まとめて）、記念日、おやすみ期間を設定可能。
- 旧「節目・通知休止」は「記念日」へ整理し、重複した通知設定フォームを撤去。記念日画面からも統一設定へリンク。
- 自動保存は種類ごとに直列化し、通信中の連続変更は最新値へ集約。画面移動後も送信を継続し、失敗時は確認済み設定へ戻して再試行を案内。設定読込時にデフォルト値をサーバーへ書き戻さない。アカウント変更時は設定画面を閉じる。
- 通知一覧は丸みのあるカード、種類別アイコン、自然な短い文言、「何分前」の表示に変更。家族の通知を含めて時系列に統合し、アルバムのフィルターを追加。投稿のお知らせから該当投稿、フォローから公開プロフィールへ遷移。
- 通知一覧の取得はソーシャル/家族を並列で実行。再取得中も既存表示を保持。未ログイン画面も短い案内へ変更。
