# Twins入力と検索履歴（2026-10-09）

実装：写真の向き補正、1600px以内の入力画像、正方形切り抜き／拡大／位置調整、カメラ起動と権限確認、元の写真を変更しない入力。既知のデモ入力IDは切り抜き後も検索候補から除外する。入力変更中の古い非同期結果は破棄する。

検索履歴は権利確認済みのデモ候補ID・検索日時・種別・結果状態だけを端末内に保存する。入力写真は保存・送信しない。履歴は最大20件、24時間経過分を次の読み込み／保存時に除外する。OSによる24時間ちょうどの自動削除を保証するものではない。保護ファイルに保存し、全履歴の削除を確認付きで提供する。

実行結果：履歴追加後の単体テスト16件成功（ios-twins-history-summary.json内の単体16件）。UIテストは最初の3回に失敗し、重複したタブのアクセシビリティ要素、確認画面の扱い、iOS27 Simulatorのカメラ利用可否の誤ったテスト前提を修正した。4回目は切り抜き→デモ検索→履歴表示→履歴削除のUIテスト1件成功、0失敗、0スキップ（ios-twins-history-available-summary.json）。iOS27 Simulatorは今回カメラ画面を利用できた。シャッターは押さず、起動・取消のみ検証した。
