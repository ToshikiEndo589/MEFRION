# 顔のアップでそっくり検索を拒否する問題の改善（2026-10-24）

## 原因と再現

犬猫判定・Vision特徴抽出・類似検索用の被写体切り抜きがそれぞれ動物の矩形検出を要求していた。写真の端まで顔が大きく写る場合、犬猫であるにもかかわらず矩形が検出されず、検索が中断されていた。

既存の犬2枚・猫1枚の画像を各100%・中央70%・中央45%で評価したところ、旧判定は7/9件を受け付け、拡大した犬と猫の2件で失敗を再現した。実際にユーザーが失敗した原本は受け取っていないため、これがすべての失敗原因であるとは断定しない。

## 修正

- 元の画像で認識できる場合は、その検出・切り抜きを維持する。
- 見つからない場合だけ、20%・45%の余白を付けた画像で再判定する。矩形座標を元画像へ戻し、実際の特徴抽出には余白を混ぜない。
- 矩形検出が失敗しても、画像分類で明確に犬または猫と認識できれば、入力画像を使って検索できる。正確な`dog`・`cat`識別子のみを採用し、信頼度0.55以上・犬猫間の差0.2以上・全ラベルの最大値に対する比率0.75以上を要求する。
- `hotdog`・`prairie_dog`・`caterpillar`などの文字列を犬猫とみなさない。種類の指定だけでは判定を通さない。
- クエリ作成内で検出結果をVision特徴・類似特徴の切り抜きへ共有し、同じ処理内の再検出による拒否と重複計算を減らす。
- 1匹しか検出していない写真で、補助姿勢検出が頭を複数提案したことだけを理由に拒否しない。複数の動物が検出された場合の単一対象チェックは維持する。

使用した画像分類API: [Apple VNClassifyImageRequest](https://developer.apple.com/documentation/vision/vnclassifyimagerequest)。外部モデル・外部画像送信・サーバー契約の追加はない。投稿時の犬猫検証は今回の変更対象ではない。
