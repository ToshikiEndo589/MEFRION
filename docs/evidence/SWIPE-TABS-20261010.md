# 左右スワイプと投稿先の並び（2026-10-10）

## 実装

- 画面の横スワイプで、ホーム内のおすすめ／フォロー中、投稿内の公開投稿／アルバムに残すを切り替える。
- 画面内タブの端では、続く同方向スワイプで隣の下部タブへ移動する。アルバム・そっくり・マイページも隣の下部タブへ移動する。下部タブバー自体のスワイプも切り替えに対応。
- 5タブの両端では止まる。縦スクロールはタブ切り替えと扱わない。60pt超、横移動が縦移動の1.5倍超の完了したジェスチャーだけを処理する。
- 公開投稿を左／初期表示、アルバムに残すを右に変更。公開の同意手続き、非公開保存、認証／権限／削除／通報／ブロックの処理は変更していない。

## 実行した検証

iPhone 17 Simulator、MEFRION scheme、Debug、署名付きビルド。隔離UIテストで未認証のクラウド画面を検証。公開データ閲覧のみで、投稿・写真アップロード・削除は実行していない。

- `.local/swipe-tabs-20261010.log`: 初回のUIテスト1件が失敗。投稿内の逆方向スワイプの反応を修正した。
- `.local/swipe-tabs-fixed-20261010.log`: 修正後の画面内切り替えUIテスト1件成功、失敗0。PNGをエクスポートして目視確認。
- `.local/swipe-five-tabs-20261010.log`: 5タブへの拡張後のテスト1件失敗（8アサーション）。親と子のスワイプ処理の干渉を修正した。
- `.local/swipe-five-tabs-fixed-20261010.log` / 同名xcresult: 最終のUIテスト1件成功、失敗0（63.626秒）。ホーム往復、縦操作でホームを維持、公開投稿初期選択と左右順、投稿内往復、タップ切り替え、5つの下部タブの左右移動と両端停止を確認。
- 対象の追跡ファイルに対する `git diff --check` 成功。
