# アルバムタブの閲覧専用ギャラリー（2026-10-18）

## 実装

- アルバムタブでは、参加中のPetの非公開写真を最初からまとめて表示。Petを先に選ぶ画面、写真追加、公開設定、家族管理の操作を置かない。
- 2列の写真カードに柔らかい影と小さなテープの装飾を加え、タップで写真全体を拡大。撮影日がある写真のみ日付を表示する。
- 「投稿 → アルバムに残す」へ追加・編集・設定を集約。Petが1匹なら追加画面へ直接進み、複数なら保存先Petを選ぶ。詳細設定は折りたたみ、頻度の低い管理を「その他の管理」へ移した。
- 家族写真は既存の本人認証付き画像ゲートウェイだけで取得。アルバムに入るたび権限を再確認し、アカウント切替・背景移行時は表示画像を破棄する。公開フィードへ自動転用しない。
- 端末内の非公開アルバムの代替画面も、Pet選択を先に求めない2列ギャラリーに揃えた。

## 実行した検証

- iPhone 17e Simulatorでゲストの5タブ・アルバム導線UI試験1件成功。
- 合成アカウントで写真を保存し、アルバムタブにPet選択なしで画像が表示されること、タブに追加ボタンがないこと、投稿タブに追加ボタンがあること、合成写真を削除することをUI試験1件で確認。最終結果は `/tmp/mefrion-album-gallery-pass-20261018.xcresult`、画面は `docs/evidence/album-gallery-simulator.png`。
- 途中のUI試験2件はテストが単独Petまたは同じ画面階層を仮定して失敗。試験用アカウントに5匹いることと画面遷移を確認し、テストを修正して再試験に成功。製品側の写真保存失敗ではない。
- 試験中に残った合成写真1枚を `scripts/clean_cloud_ui_fixture.py` で削除し、試験用Petの公開を停止。実利用者データは対象外。
- 最終コードでiPhone 16向け署名付きDebugビルド成功、接続中の実機へ上書きインストール・起動成功。
