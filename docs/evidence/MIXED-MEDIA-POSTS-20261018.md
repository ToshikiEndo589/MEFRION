# 写真・動画の混在投稿（2026-10-18）

- 公開投稿と家族アルバム保存の両方で、写真・動画を合計10件まで選択可能にした。動画は選択時に5分を超えるものを拒否し、端末でMP4に変換する。50MB未満に収まらない場合は、解像度を下げて再変換する。
- 投稿タブの「アルバムに残す」は新規選択だけを表示し、過去のアルバム一覧・管理機能を出さない。管理導線はマイページの「アルバムの設定」に集約した。
- 動画にポスター画像を付け、ホーム・投稿詳細・マイページ・アルバムの一覧では静止画を先に表示する。タップ時のみ動画本体を取得して再生する。
- Supabase migration `202610180052_mixed_media_posts.sql` と、公開処理のPL/pgSQL列名衝突修正 `202610180053_mixed_media_publication_fix.sql` を検証プロジェクトに適用した。
- `private-video` と既存の `public-image` Edge Function を更新した。後者は `format=video` の場合だけ公開動画を返し、公開可否を前後で確認する。既存のゲスト向け公開認証設定を使うので、新たな認証緩和は不要。
- Macの開発用ワーカーは動画の公開用MP4を再変換し、メタデータを除去してから公開用Storageに配置する。

## 検証

- 端末用・Simulator用のiOS Debugビルド成功。接続中のiPhone 16へインストール・起動成功。
- 合成専用Petで、写真9件＋動画1件の混在公開、11件の拒否、動画ポスター・動画本体のゲスト取得を確認。合成データは検証後に削除した。
- 別アカウントから非公開動画を取得できないこと、写真のみの既存公開処理31項目、関連ユニットテスト14件を確認。

## 運用上の残件

- 公開用変換ワーカーはMac稼働中の60秒間隔で、常時稼働のクラウド処理ではない。Mac停止中の投稿は処理待ちになる。この点は従来の写真投稿と共通。
- 実機での写真ライブラリからの動画選択・長尺動画の拒否表示は、本人による画面操作で最終確認が必要。
