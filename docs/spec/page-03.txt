01. プロダクトの目的と変えてはいけない原則
1.1 体験の中心
MEFRIONは犬と猫を主役にした、家族内の成長アルバムを日常利用の中心に置く記録・交流サービスです。写真を入れるだ
けで撮影時期に沿ったアルバムができ、家族の写真が集まり、節目を振り返れます。公開したい記録だけがSNSにつながりま
す。Twinsは、公開参加に同意した犬猫の中から似た子と出会う入口です。
価値の循環：写真を残す → 家族の写真が届く → 過去を振り返る → また残す。外部ユーザーが少なくても成り立つことが重
要です。さらに公開初期は、運営管理の複数Petプロフィールから通常投稿と同じ見た目の権利確認済みコンテンツを用意
し、「見つける」の空白を防ぎます。実ユーザーの活動人数・感想・交流を偽造しないことが条件です。
3つの行動原則
犬猫が主役：人間アカウントはログイン・権限・責任の主体。公開プロフィールの主役はPetです。
非公開が初期状態：家族内の写真は選択なしにSNS、検索候補、共有ページ、外部AIへ渡しません。
記録は自由：連続投稿ランキングや催促を設けず、成犬・成猫・シニア、亡くなったPetにも配慮します。
1.2 利用者像
利用者 最初の行動 主な価値
飼い主・Pet管理者 Petを作成し写真を追加 成長アルバム、節目、SNS公開を任意で
選択
招待された家族 招待を承認して写真を追加 同じPetの非公開アルバムを共同で育て
る

ロー
1.3 画面・ナビゲーションの最上位仕様
iPhoneの下部タブはホーム / そっくり / 投稿 / マイページの4つとします。ホームは「フォロー中 / 見つける」。投稿タブは写
真を選んだ後、アルバムに残すを初期選択とし、別操作でSNSに公開を選ばせます。マイページはPetを所有しない閲覧者も
使えるようにします。日本語を第一言語とします。
