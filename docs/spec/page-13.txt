公開前の事業側の承認：投稿する写真、原稿、Pet表示名、利用許諾の証跡、プロフィールの説明、配信計画、利用規約の文
言を確認する。Codexはデモデータで仕組みを実装し、これらの素材を本番へ勝手に配置しない。
PET-03 公開Petプロフィール
公開範囲を選んだ項目だけ表示します。写真、Pet名、犬種/猫種、任意の年齢・性格・紹介文、公開投稿数とフォロワー数を
表示。管理者のフォロー中数、人間の私的プロフィール、家族内写真数は公開Petに載せません。飼い主がPetの公開そのもの
を解除したらプロフィール、検索、共有、推薦から消します。
POST-01 投稿作成
写真は最大4枚、本文は任意で最大500文字。管理する複数Petを紐づけ、メインPetを1匹選べます。公開前に対象Petの公開
設定、写真の利用権限、家族提供者の同意を検証します。投稿後は本文編集と投稿削除が可能です。犬猫が主役かを自動
チェックするなら、誤判定時の再審査・修正導線を必ず用意します。
投稿ボタンの初期動作：写真選択 → 「アルバムに残す / SNSに公開」を表示 → 初期はアルバムを選択。誤って公開する危険
を避けるため、公開時は操作の種類を明示します。招待家族は管理者でないPetについてSNS公開できません。
SOC-01 交流機能
フォロー：人間が公開Petをフォローする。Petの所有者は1人でも複数Petを管理可能。
いいね：人間アカウント単位で対象1つにつき1回。再度押すと解除。
保存：本人だけが見られる一覧。保存対象の公開が終了したら内容を露出しない。
コメント：親コメントと返信1階層のみ。返信先を明示する。
発言名義：人間名義または自分が管理するPet名義。最後に使った名義を記憶。ただし権限は人間IDで検査する。
ブロック：人間IDを単位として相手のすべてのPet名義へ適用する。
SEARCH-01 検索
検索対象は公開Petの名前・犬種/猫種です。部分一致や表記ゆれ、検索結果なし、公開終了、ブロック状態を扱います。一般
公開でない人間名、家族アルバム、ゲストのTwins画像は索引に入れません。
NTF-01 通知
種類 初期方針
コメント・返信 アプリ内 + 本人が許可したプッシュ
家族の新しい写真 招待家族だけに通知。即時 / まとめて / オフ
公開節目・Twins新候補 対象・条件を明示して本人が希望した場合のみ
いいね・フォロー アプリ内中心。多い反応はまとめて通知
フォローとは別に「この子の節目を受け取る」を選べるようにします。対象は公開済みの節目だけです。家族内の記念日を勝
手にプッシュしません。通知許可は文脈の中で求め、拒否しても利用できるようにしてください。アプリ起動時にあらゆる権
限を一斉要求しないでください。
