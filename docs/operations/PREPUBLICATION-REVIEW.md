# 公開投稿の確認手順

2026-11-02 以降、利用者の公開投稿は写真・動画の処理が終わっても自動公開されません。状態は `review` となり、本人には「公開前の確認中」と表示されます。運営が承認した時点で公開されます。運営素材の権利確認フローは従来どおりです。

1. 二段階認証済みの運営アカウントで `https://mefrion.vercel.app/console/content` を開く。
2. 投稿文と、各写真・動画を確認する。動画は再生し、ペットの写り込みと不適切な内容を確認する。
3. 判断理由を入力し、「確認して公開」または「公開しない」を押す。判断理由は運営記録であり、利用者へ公開されない。
4. 確認待ちは古い順に最大50件表示される。処理後に再読み込みすると次の投稿が現れる。

投稿文とコメントにはサーバー側の一次フィルタも適用されます。違反表現や連絡先・URLを含む投稿は拒否されます。このフィルタだけで全ての違反を検出できるわけではありません。公開済みの投稿・コメントの通報窓口と対応手順は継続して運用してください。

退会では公開表示とアクセスを直ちに停止し、残存ファイルと認証情報は通常24時間以内に削除します。削除完了をサーバーが確認した後、申し込んだ端末でアプリを開くと完了を表示します。24時間を超えた問い合わせは `mefrion@mefrion.com` で受け付けます。
