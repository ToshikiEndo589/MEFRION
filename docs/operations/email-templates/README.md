# メール配信の接続準備

2026-10-17、Brevo専用SMTPをSupabase Authに接続し、確認・復旧のテンプレートを本ファイルと同じ内容で保存した。件名は「MEFRION メールアドレスの確認」「MEFRION パスワードの復旧」。本人からiPhoneでの確認メール受信、コード登録、初回Pet作成まで完了したとの報告がある。復旧・再送・期限切れは未検証。Tokenやメールアドレスをアプリのログ、URL、監視通知へ転記しない。

正式公開前に独自ドメインと送信元認証、流量制限を整え、実際の新規登録・確認・再送・期限切れ・復旧・取消を検証する。現在のGmail連絡先はBrevo上で送信元として確認済みだが、独自ドメイン未取得のため代替ドメインへ書き換わる暫定運用。チャットにSMTPパスワード/秘密鍵/OTPを送らない。

公式のToken変数: https://supabase.com/docs/guides/auth/auth-email-templates

2026-10-15: 一般メールへの登録不能を確認した原因は、専用SMTP未設定。Supabase公式は既定送信を組織チームの事前承認アドレスに限定し、本番利用不可としている（https://supabase.com/docs/guides/auth/auth-smtp）。iOS側には送信先未許可・429・登録済みの表示、確認用パスワード欄、リンク確認案内、再送導線を追加した。実メールの到達はまだ検証していない。送信元を検証したSMTPの契約・DNS設定、Supabaseへの接続、テンプレートの適用、一般アドレスでの新規登録・再送・復旧・期限切れ試験が完了するまで「登録機能完成」としない。
