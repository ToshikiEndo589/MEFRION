# 運営ワークスペース

`/console` に運営ホーム、要対応件数、利用状況、公開投稿検索・対応履歴、問い合わせ記録を追加。
すべてのRPCは既存の運営権限・有効なセッション・TOTPを検証する。家族アルバム原本と通報者の情報は取得しない。

問い合わせはメールで受けた内容を運営者が記録する。メールボックスの自動同期は未接続。担当者、期限、優先度、状態、解決内容を管理し、同時更新はversionで拒否する。

利用状況は登録人数、公開件数、登録後の初投稿人数、複数日に投稿した人数、DB・Storage容量。閲覧継続率や金額の請求予測とは区別する。

メール通知は `operator-alerts` Edge Function。固定の運営アドレスに件数だけを送り、個人情報・投稿文は含めない。Brevo APIキーを `BREVO_API_KEY` としてサーバーの秘密設定へ登録する必要がある。既存のSMTPキーとは別。送信は最大1時間に1通、同じ状況の再通知は24時間後。失敗は15分後に再試行する。

配備・送信確認後、SQLで次を実行して定期処理を有効にする。

```sql
select cron.schedule('mefrion-operator-alerts','*/5 * * * *','select mefrion_private.operator_alert_tick()');
```

Vercel FirewallとSupabaseへの直接通信は各社の公式画面で確認する。外部ログの自動転送は未接続。認証情報を画面やリポジトリに保存しない。
